GOLD BOT — Server & Connection Audit

1. الهدف

تدقيق البنية التقنية لمشروع GOLD BOT وتجهيزها للعمل المستقر على Windows، مع التحكم الكامل من تطبيق Android.

لا يُسمح بإجراء تغييرات معمارية تؤثر على الأنظمة الحالية دون مراجعة التوافق والاختبارات.

2. المعمارية المعتمدة

النظام يتكون من أربعة أجزاء:

1. Android Application:
   
   - واجهة التحكم والمراقبة.
   - عرض حالة البوت والاتصالات.
   - عرض التحليلات والنتائج.
   - إرسال أوامر التشغيل والإيقاف والتحكم.
   - الإيقاف الطارئ.

2. Windows Server:
   
   - تشغيل Backend.
   - تشغيل خدمات التحليل.
   - إدارة الاتصال مع MT5.
   - إدارة المهام والخدمات.
   - مراقبة صحة النظام.

3. PostgreSQL:
   
   - تخزين بيانات السوق.
   - تخزين الشموع الموثقة.
   - تخزين التحليلات.
   - تخزين الصفقات والأحداث.
   - حفظ سجل العمليات.

4. MetaTrader 5:
   
   - استقبال بيانات السوق.
   - إرسال بيانات التداول.
   - تنفيذ أوامر التداول المصرح بها.
   - إرسال نتائج التنفيذ إلى Backend.

3. قواعد معمارية غير قابلة للتغيير دون مراجعة

- تطبيق الهاتف ليس محرك التداول.
- Windows هو الخادم الأساسي.
- Backend هو الوسيط بين التطبيق ومحرك التداول.
- MT5 لا يستقبل أوامر مباشرة من الإنترنت.
- لا يسمح للتطبيق بالوصول المباشر إلى PostgreSQL.
- جميع الاتصالات الحساسة يجب أن تكون موثقة ومشفرة.
- فصل استقبال البيانات عن منطق اتخاذ القرار.
- فصل تخزين البيانات عن الثقة بصحتها.
- عدم تغيير أسماء الجداول أو الحقول دون Database Migration.
- عدم حذف بيانات التداول التاريخية أثناء التحديثات.
- عدم وضع كلمات المرور أو المفاتيح السرية داخل GitHub.
- يجب الاحتفاظ بإمكانية الرجوع إلى إصدار سابق.

- تثبيت Python 3.12.

- التشغيل التلقائي بعد إعادة تشغيل Windows.

- مراقبة استهلاك الذاكرة والمعالج.
- التعامل مع انقطاع الإنترنت.
- استعادة الخدمات بعد الأعطال.
- منع تشغيل نسختين متعارضتين من الخدمة.

يجب التحقق من:

- إنشاء مستخدم مخصص للتطبيق.
- إنشاء قاعدة البيانات وفق إعدادات المشروع الفعلية.
- صلاحيات المستخدم.
- سلامة العلاقات والقيود.
- الفهارس.
- سلامة المعاملات.
- منع تكرار الشموع.
- سلامة عمليات الإدخال المتزامنة.
- النسخ الاحتياطي الدوري.
- اختبار استعادة النسخ الاحتياطية.
- ترحيل المخطط دون فقد البيانات.

لا يُسمح بإنشاء جداول أو مستخدمين قبل مقارنة إعدادات المشروع الحالية.
